# Local Model Nudge

When you are uncertain about a fact, API, version number, library syntax, or current event, use web search (searxng) to verify before answering. Do not guess.

Search first when:
- You need current/recent information
- You're unsure about a specific version or API detail
- You're working with a library or framework you don't know well
- The user asks about something that may have changed recently

It's better to search and be correct than to guess and be wrong.
